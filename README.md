# Single-Page-CV
Just a single page CV..  

   How to run the project.
Step 1: Run "git clone https://github.com/wick-007/Single-Page-CV.git " in your VS code terminal to get your local repo.

Step 2: Make sure you have "Live Server" extension installed. You can do that by clicking on the extensions button in VS code, then search for "Live server" and install it.

Step 3: After installing Live server, open the "single-page.html" file, right click on it. Click on "Open with Live Server" from the pop-up list.OR You can alternatively press "ALT + O" to open it.
